# 🎵 Focus Flow

Projeto acadêmico desenvolvido para a disciplina de **Introdução ao Desenvolvimento Front-End** do curso de **Bacharelado em Ciência da Computação da UNIVEM**.

O projeto tem como objetivo explorar a construção de interfaces modernas utilizando **Tailwind CSS** e **JavaScript**, aplicando conceitos de responsividade, componentes visuais e interatividade em uma landing page inspirada em plataformas de streaming musical.

---

## ✨ Sobre o projeto

O **Focus Flow** foi desenvolvido com uma proposta visual moderna inspirada em interfaces de aplicativos como Spotify e Apple Music, utilizando uma estética dark com gradientes, efeitos visuais e elementos interativos.

A aplicação apresenta:

* Hero section estilizada
* Navbar responsiva
* Carrossel automático de álbuns
* Formulário com floating labels
* Footer personalizado
* Layout responsivo para diferentes dispositivos
* Interações com JavaScript

---

## 📋 Requisitos da atividade

A atividade proposta em aula consistia em adicionar ao projeto base os seguintes componentes:

* Navbar (menu superior)
* Modo dark/light
* Carrossel
* Formulário de cadastro simples
* Interações com JavaScript

---

## 🚀 Funcionalidades implementadas

* ✅ Navbar fixa e responsiva
* ✅ Interface moderna com Tailwind CSS
* ✅ Carrossel horizontal automático de álbuns
* ✅ Cards com efeitos hover e animações
* ✅ Formulário de inscrição com floating labels
* ✅ Botões interativos com efeitos visuais
* ✅ Layout responsivo para desktop e mobile
* ✅ Footer personalizado
* ✅ Estilização inspirada em plataformas de streaming
* ✅ Interações com JavaScript puro

---

## 🛠️ Tecnologias utilizadas

* HTML5
* Tailwind CSS (CDN)
* JavaScript
* CSS Utility First

## ▶️ Como executar o projeto

1. Faça o download ou clone este repositório:

```bash

```

2. Abra a pasta do projeto.

3. Execute o arquivo:

```text

```

em qualquer navegador moderno.

> Como o projeto utiliza Tailwind CSS via CDN, é necessário conexão com a internet para o carregamento correto dos estilos.
