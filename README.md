# Focus Flow

Projeto acadêmico desenvolvido para a disciplina de Front-End do curso de **Bacharelado em Ciência da Computação da UNIVEM**.

O objetivo da atividade foi praticar a criação de interfaces usando **Tailwind CSS**, acrescentando componentes visuais e interações com JavaScript.

## Requisitos da atividade

A atividade solicitava acrescentar ao exemplo feito em aula:

- Navbar, menu superior
- Modo dark/light
- Carrossel
- Formulário de cadastro simples
- Interação com JavaScript

## Funcionalidades implementadas

- Navbar fixa no topo da página
- Alternância entre modo claro e modo escuro
- Troca automática de imagens conforme o tema escolhido
- Carrossel horizontal de álbuns com movimento automático
- Formulário simples de inscrição com campos de nome e email
- Layout responsivo com Tailwind CSS
- Menu mobile com JavaScript próprio
- Footer com informações do projeto e links sociais

## Tecnologias utilizadas

- HTML5
- Tailwind CSS via CDN
- JavaScript

## Como executar

Abra o arquivo `Exerciciobreno.html` diretamente no navegador.

Como o projeto usa Tailwind via CDN, é recomendado estar conectado à internet para carregar os estilos corretamente.
